# 第1章：工程概论

## Core Idea
工程是技术要素与非技术要素集成的造物社会实践活动，本章建立全书根基：理解工程"是什么、怎么运行、如何思考"，并系统提出工程理念与工程观（系统观、社会观、生态观、伦理观、文化观）。

## Frameworks Introduced
- **工程本质观（要素集成论）**：工程的本质 = 各种资源和要素的集成过程、集成方式和集成模式的统一
  - When to use: 分析任何工程的构成与运行方式时
  - How: ①看技术要素（能源、材料、装备、工艺、控制）与非技术要素（资源、资本、土地、劳动力、市场、环境）的互动；②两类要素相互影响——非技术要素变化会改变技术要素集成方式，反之亦然
- **工程活动六环节模型**：理念与决策 → 规划与设计 → 组织与调控 → 实施与建设 → 运行与评估 → 更新与改造
  - When to use: 评估一个工程处于生命周期哪个阶段、哪里可能出问题
  - How: 按环节逐段审查；特别注意理念与决策环节（"决策失误是最大的失误"）
- **工程决策权衡框架**：理性 + 情感 + 意志三因素，权衡、协调、优化是决策的灵魂
  - When to use: 面对多目标、多利益方冲突的工程决策
  - How: ①以理性为基石（调查、方案设计、比较评价）；②承认理性有局限，情感与意志会介入；③在经济效益/社会效益（义与利）等矛盾间权衡协调
- **工程思维四特征**：科学性、艺术性、操作性与集成性、可靠性-可错性-容错性
  - When to use: 判断一种工程思维方式是否合格
  - How: 工程问题答案非唯一（艺术性）；必须遵循科学规律（科学性）；须落实到操作（操作性）；对风险保持清醒并用容错性提升可靠性
- **工程系统分析六要素**：问题、目标、方案、模型、评价、决策者
  - When to use: 对工程做全面定性与定量分析
  - How: 预测、建模、优化、仿真、比较与评价；步骤：认识问题→确定目标→综合方案→构建模型→优化仿真→系统评价→做出决策

## Key Concepts
- **工程**：创造和建构新的人工物的社会实践活动，包含工程过程和工程成果
- **工程理念**：人们在长期工程实践基础上形成的对工程发展规律、方向的思想信念与理想追求的集中概括；新时代核心是"以人为本，人与自然、社会协调发展"
- **工程决策**：工程决策主体在工程活动各阶段做出的所有决定行为及选择过程
- **工程创新**：发生在工程活动中的创新，具有集成性、社会性、建构性、可靠性特点
- **工程文化**：人们在从事工程活动时创造并形成的关于工程的思想理念、行为规则、习俗习惯等；含理念层、知识层、制度层、规范层、习俗层五层次
- **工程共同体**：投资者、管理者、工程师、工人等不同成员共同构成的工程参与群体
- **工程风险**：工程建设和运行过程中人身财产损失及其可能性

## Mental Models
- **用"人-自然-社会和谐"评估一切工程**：新时代工程理念的核心，越重大工程越要通盘考虑是否造福人民、能否持久造福
- **工程思维 = 造物思维**：它渗透于工程所有环节，与科学思维（求唯一答案）的根本区别是工程答案不唯一
- **把工程看成系统**：工程自身是复杂系统（人、物料、设备、能源、信息等要素），与外部环境构成更大系统，须从系统观把握
- **工程文化是工程的"黏合剂"**：施工事故的深层原因往往不是技术问题，而是文化素质和传统习惯问题

## Anti-patterns
- **"征服自然"的工程理念**：盲目征服自然、只讲经济功能，破坏生态循环（"自然资源-产品-废弃物"单向流动），导致生态危机
- **三门峡式决策失误**：决策前不充分听取反对意见（黄万里教授预警被忽视），高坝大库方案造成泥沙淤积、渭河倒灌、"小水酿大灾"——决策失误是最大的失误
- **只看单一价值**：极端追求某一价值（如经济）而牺牲其他价值，使工程其他价值变为负值
- **忽视工程文化**：把施工事故只归因于技术/能力，忽略文化素质与习惯的深层作用

## Worked Example
**花旗银行大厦事件（勒曼歌尔）**：
1. 设计创新：勒曼歌尔1977年设计纽约花旗银行大厦，四根立柱支撑于底部框架各边中点而非顶点，大厦悬空于教堂之上，体现工程思维的艺术性（非唯一解）。
2. 隐患发现：学生来电称其教授质疑立柱位置；勒曼歌尔将问题带到课堂让学生计算，发现载荷增加40%时焊缝局部应力剧增至160%，16年一遇大风可能导致整体坍塌。
3. 伦理抉择：他没有掩盖问题（尽管公开会损害声誉、导致公司破产），而是快速拟定修复补救计划、测算成本，上报投资方并获得批准。
4. 结果：花费数百万美元修复；修复接近完成时飓风来袭，大厦安然无恙。体现工程师对工程和公众高度负责、审慎果敢处理危机的伦理品质。

## Key Takeaways
1. 工程 = 要素集成，技术要素与非技术要素必须协调互动，缺一不可。
2. 完整工程活动六环节中，理念与决策是第一位的——决策失误是最大的失误。
3. 工程问题答案不唯一，决策者需要在多方案中权衡、协调、优化。
4. 工程思维必须承认可错性，用容错性方法提高可靠性（如计算机系统的容错设计）。
5. 新时代工程理念以人为本，工程师须把公众安全、健康和福祉放在首位。
6. 工程文化决定工程品质，事故深层原因往往是文化问题而非单纯技术问题。
