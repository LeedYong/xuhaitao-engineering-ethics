# 第2章：工程伦理学的道德框架

## Core Idea
本章建立工程伦理学的理论根基：兴起背景、研究对象、学习方法，以及四大核心伦理理论（功利论、义务论、契约论、美德论），并以福特平托事件演示如何用四大理论分析真实工程伦理困境。

## Frameworks Introduced
- **四大伦理理论框架**（全书最重要分析工具）
  - **功利论（功利主义/后果论）**：以行为结果判断对错，追求"最大多数人的最大幸福"
    - When to use: 需要评估行为后果、做成本效益分析时
    - How: ①计算行为涉及每个个体的苦乐总和（每人计为1）；②增加最大快乐值即善；③常用方法=成本效益分析。分行为功利主义（看单次直接后果）与规则功利主义（遵循普遍规则、看长期总体后果）
  - **义务论（道义论）**：以行为动机和规则判断对错，人是目的不是手段
    - When to use: 判断行为本身是否正当、动机是否善良时
    - How: ①道德是自主自律行为；②道德价值取决于动机（责任动机）；③道德是可普遍化的绝对命令（己所不欲勿施于人）。分行为义务论与规则义务论；罗斯提出七种显见义务（忠诚、补偿、感恩、正义、慈善、自我改善、不伤害别人）
  - **契约论**：以社会约定、制度契约为判断标准
    - When to use: 分析行为是否符合社会共识、制度规范时
    - How: 通过订立契约把个人行为动机与规范伦理看作社会协议；罗尔斯正义两原则：①自由原则（人人平等的基本自由）；②差异原则（机会均等、惠顾最少数不利者）
  - **美德论**：关注行为人本身的品德
    - When to use: 评价"应当成为什么样的人"时
    - How: 关注品德胜过权利、义务和规则；工程美德=诚信、负责、专业、胜任、诚实、勇敢、公正、谦虚等；麦金太尔提出职业的内在善与外在善
- **工程伦理学三层分析视角**：行动者（美德论）、行为（义务论）、结果（功利论）；契约论注重程序合理性
- **狭义与广义工程伦理学**：狭义=工程师职业伦理；广义=工程全流程所有参与者的道德决策与行为

## Key Concepts
- **伦理 vs 道德**：道德是公认规范，伦理是对规范的理性反思；道德讲奉献诉诸情感，伦理讲公平诉诸理性；道德是个人境界，伦理是群体关系
- **工程伦理学**：研究工程实践中道德上的决策、政策和价值；理解工程中的道德价值、解决道德问题、论证道德判断
- **伦理困境**：价值标准多元化与现实复杂性导致的具体情境下道德判断和选择的两难境地
- **成本效益分析**：功利主义的重要方法，把价值因素转换为统一标准并计算，选择产生最大效益的方案；缺陷：难以预测未来、效益最大化可能对少数人不公平
- **绝对命令（康德）**：不受条件限制的义务，把自己或他人当作目的而不是手段
- **显见义务（罗斯）**：大部分义务都有合理例外；不杀人和保护无辜者生命是比其他原则更紧迫的义务
- **差异原则（罗尔斯）**：机会均等并惠顾最少数不利者，减少社会因素和偶然运气影响

## Mental Models
- **用"三个评价对象"拆解任何伦理案例**：行动者（美德）、行为（义务）、结果（功利）——案例分析的标准切入点
- **功利论看结果、义务论看动机、契约论看程序、美德论看人品**：四把尺子对比分析同一行为
- **工程伦理学的"双向螺旋"**：从伦理到工程（用伦理约束工程），从工程到伦理（工程发展改变伦理观念）
- **伦理不是习俗**：存在的不一定是合理的，风俗有过去的合理性，未必有现在和未来的合理性

## Anti-patterns
- **滥用成本效益分析量化生命**：福特平托事件——用20万美元/人的命价计算赔偿低于加装11美元/辆的安全装置成本，选择不安装。违背功利论"最大多数人的最大幸福"，把生命当金钱计算是不道德行为
- **只忠诚雇主而忽视公众责任**：早期工程师团体章程过于强调对雇主忠诚、很少涉及公众责任，受到非议
- **利己主义主导工程决策**：工程师为自身利益忽略公司利益、公众利益甚至社会利益，不符合工程伦理潮流
- **工程师当"边缘人"定位模糊**：工程师兼有劳动者、管理者、科学家、商人的多重身份，被科学和商业拉向对立面，导致职业伦理定位困境

## Worked Example
**电车难题（引导案例）**：
1. 情境一：拉杆让电车转向——牺牲1人救5人，功利论认为正确（5人生命价值>1人），义务论陷入"不杀人"与"救人"两个义务的冲突，美德论在"救人美德"与"不杀人罪责"间两难。
2. 情境二：天桥上推下胖子阻挡电车——功利论同样支持（5>1），但把他人当作手段，违反义务论"人是目的不是手段"。
3. 启示：不同伦理理论对同一困境给出不同甚至冲突的判断，这正是伦理困境的实质。

**福特平托事件（应用案例）**：
1. 事件：福特平托车未完成性能测试即上市，油箱设计缺陷，追尾即爆炸起火；小格林萧被严重烧伤（90%烧伤、60多次手术）。
2. 成本效益分析：加装11美元防护装置×1250万辆=1.375亿美元；不安装最多赔偿4953万美元（180人死亡×20万美元+180烧伤×6.7万美元+2100辆车×700美元）→福特选择不安装。
3. 伦理困境：管理层（企业效益vs公众安全）、工程师（对雇主忠诚vs对公众责任，坚持建议可能被解雇）。
4. 四大理论分析：功利论→牺牲消费者生命换取利润违背最大多数人的最大幸福；义务论→企业有义务提供安全产品、无权利因履行工程师义务而开除员工；契约论→违反企业与消费者的安全契约；美德论→企业缺失诚信、负责的美德。

## Key Takeaways
1. 工程伦理学的核心目标：制定道德规范并应用于工程实践。
2. 四大伦理理论各有侧重：功利论重结果、义务论重动机规则、契约论重程序共识、美德论重品德，实际分析常需结合使用。
3. 伦理困境 = 多元价值标准与现实复杂性导致的两难，无法用单一理论简单解决。
4. 成本效益分析是有效工具，但不能用来量化生命、牺牲少数人利益。
5. 工程师面临"忠诚于雇主"与"保护公众"的双重义务冲突，这是工程师职业的特殊困境。
6. 中国的工程伦理建设以宏观伦理为目标（可持续、环保、以人为本），同时也要关注微观伦理。
