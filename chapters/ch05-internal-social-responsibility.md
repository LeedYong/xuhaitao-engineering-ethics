# 第5章：工程的内部社会责任

## Core Idea
本章聚焦工程共同体的内部伦理关系：工程师作为企业雇员的职业特征、职业素质、伦理决策（与管理者冲突、责任、忠诚与举报、诚实），核心矛盾是"对雇主忠诚 vs 对公众责任"。

## Frameworks Introduced
- **工程师职业特征六维度**：①专业训练（长期理论+正规教育学位+职业初期技能积累）；②行业属性（职业与行业密不可分，包含公共元素）；③谋生手段（职业第一要义是生存，也满足社会需求与个人需要）；④流动性（探索→立业→维持→离职四阶段；奥德弗ERG理论：生存/关系/成长需要；人才流动是优化资源配置的必然要求，但可能带来侵权与安全威胁）；⑤承担义务（用知识与技能增进全人类福祉；保护公共健康、安全和福祉）；⑥遵守职业标准（职业道德+职业功能、工作内容、技能要求、相关知识）
- **工程师发挥作用的五大领域**：①设计（工程活动的首要环节，遵守设计规则与标准，考虑安全隐患）②技术评估（技术价值评价[先进性+适用性]、经济价值评价、社会价值评价）③质量和安全（严格执行ISO9000等质量管理规范，制定安全分析规范）④协调（合理分配资源，有序高效开展工程活动）⑤社会意识（理解技术对社会的作用和反作用；任何设计决策都不是社会中立的）
- **工程师伦理决策框架（面对雇主）**：不参与（拒绝）、不服从、举报三个层次递进
  - 不参与/不服从：拒绝参与违背职业伦理的项目；注意不要以道德为借口逃避无聊工作或私人恩怨；雇主应尊重合理的不参与要求
  - **举报**：通过超出批准的组织渠道，将重大道德或法律问题信息传递给能采取行动的决策者；特点：未经批准+向公众揭露组织内部信息；分类：内部/外部、公开/匿名
  - **乔治的举报三条件**：①确认产品对公众危害严重；②已向上级报告忧虑；③组织内部没有满意答复——满足时举报成为道德义务；戴维斯补充：举报的道德动机是避免成为不当行为的共犯
- **工程诚实四维度**：①不说谎（有意传达错误或误导信息；投标不瞒报预算；欺骗性广告方式：露骨谎言、半真半假、夸张、虚假影射、模糊误解）；②不侵权（知识产权：著作权、专利权、商标权；商业机密保护）；③避免科研欺诈（伪造、篡改、剽窃）；④信息公开（全面客观有效告知关系人，尊重知情权）

## Key Concepts
- **内部社会责任**：工程师作为企业雇员需要对企业担负的责任（与外部社会责任相区别又联系）
- **工程师（历史定义）**：在各个历史时期负责工程项目实施和组织管理的人员；历史分五阶段：古代文明时期（公元前4000-前600年，美索不达米亚/古埃及/印度河文明）、古典时期（前600-前400年，古希腊/罗马）、中世纪和近代早期（500-1750年，京杭大运河1799千米、专利制度萌芽）、工业化时期（1750-1945年，英国斯密顿/瓦特、美国西点军校、法国巴黎理工、德国工程师协会）、二战后（技术反思、工程师协会纷纷成立、技术大学兴起）
- **工程师职业准入制度**：高校教育→职业实践→资格考试→注册→执行管理
- **内在善与外在善（伯恩/丛杭青）**：工程实践赋予工程师职业能力实现技术卓越（内在善），通过技术制品转化为外在善
- **利益相关者**：股东、管理者、员工、债权人、客户、供应商、行业竞争者、国家；企业是利益相关者的契约集合体（金泽良雄：企业受全社会委托）
- **科研欺诈**：伪造（编造不存在数据）、篡改（蓄意修改数据）、剽窃（使用他人成果不给荣誉）

## Mental Models
- **"工程师是社会责任的承担者"**：工程师不仅对雇主负责，更因专业知识承担面向未来的预防性/前瞻性责任
- **忠诚≠失职**：对企业尽专业服务是最大忠诚；对企业违法损害公共利益的行为不予置评就是失职（长生疫苗案）
- **举报是最后手段**：内部渠道优先→良知拒绝→举报；举报者应尽量利用组织内程序、保密、对事不对人、保留记录、提出正面建议
- **"任何设计决策都不是社会中立的"**：工程师必须看到技术对社会的作用和反作用（共享单车案例：方便出行同时占用公共资源、资金监管问题）
- **能力即责任（伯恩）**：工程本质是能力赋予活动，专业知识深度是履行伦理责任的前提

## Anti-patterns
- **长生疫苗式逐利**：无视产品质量、企业信誉、公众生命健康，私自篡改生产记录、随意更改生产参数、降低生产标准——对社会公众生命健康的漠视，最终自我毁灭（退市）
- **挑战者号式压制异议**：罗杰·博伊斯·乔利等工程师多次提出O形环低温失效风险，被管理层忽视——公司主管为取悦客户NASA从"不要发射"变为"可以发射"
- **波音MCAS式设计缺陷**：为弥补737旧机体装新大发动机的气动问题，安装无交叉检测、无驾驶舱警告的MCAS自动压头系统，两次空难——为商业竞争牺牲安全设计
- **小保方晴子式科研欺诈**：STAP干细胞造假、图片重复使用，撤稿+导师自杀——伪造、篡改、剽窃摧毁职业生涯并污染科研生态
- **埃航/狮航式隐瞒**：737MAX8半年内两起空难，暴露安全信号未及时向机组传达

## Worked Example
**挑战者号航天飞机失事（引导案例）**：
1. 事件：1986年1月28日，挑战者号发射73秒后爆炸，7名机组人员遇难，价值12亿美元航天飞机化为乌有。
2. 技术原因：发射当天低温（华氏40度以下）使右侧固体助推器O形环硬化失效，密封失灵，火焰从缝隙喷出，最终点燃外挂燃料箱。
3. 人为因素：工程师博伊斯·乔利在发射前6个月就发现O形环问题并保留照片证据；发射前夜瑟奥科尔公司工程师建议"不要发射"，但副总裁暂停会议5分钟后，总裁为取悦最大客户NASA拍板"可以发射"。
4. 伦理教训：管理层将客户关系凌驾于安全证据之上；工程师的警告被层层忽视；事发后调查中作证的工程师（如罗杰·博伊斯·乔利）遭报复失去27年职业生涯——保护举报人是制度必须。

## Key Takeaways
1. 工程师职业特征是专业训练、行业属性、谋生手段、流动性、承担义务、遵守职业标准六维统一。
2. 内部社会责任要求工程师在设计中预判风险、技术评估、保证质量安全、协调工程、保持社会意识。
3. 面对雇主的不当决策，行动层级：内部沟通→不参与/良知拒绝→举报；公众安全永远优先于对雇主的忠诚。
4. 举报的三条件（危害严重、已上报、内部无效）满足即成为道德义务；举报是避免成为不当行为共犯。
5. 诚实四维度（不说谎、不侵权、避免科研欺诈、信息公开）是工程师职业底线。
6. 挑战者号、波音MCAS、长生疫苗警示：任何"取悦客户""压缩成本""追求速度"都不能凌驾于公众安全。
