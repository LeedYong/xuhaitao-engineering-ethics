# 第7章：全球化工程中的伦理

## Core Idea
本章面向全球化语境：文化差异（霍夫斯蒂德五维度）、伦理相对主义与绝对主义、超文化规范、最佳实践标准，以及中国工程"走出去"的价值原则与伦理规范、"一带一路"的生态伦理问题。

## Frameworks Introduced
- **霍夫斯蒂德文化五维度模型**（文化差异分析工具）：
  - 个人主义vs集体主义：个人主义重视自身价值与需要（美国）；集体主义以"群内/群外"区分，期望群体照顾并以忠诚回报（中国、日本）
  - 权力距离（PDI）：对权力分配不平等的接受程度；PDI高=阶级观念强（日本、中国）；PDI低=平等交流（美国）
  - 不确定性避免程度：防止不确定情境的迫切程度；高=高度紧迫感和进取心（日本、中国，全面质量管理有效）；低=放松、冒险探索（美国）
  - 男性度vs女性度：居统治地位的价值标准；男性社会（美国：自信武断进取好胜）；女性社会（中国：注重和谐伦理道德）
  - 长期取向vs短期取向：长期=节俭、恒心、持久、展望将来；短期=注重过去现在、尊重传统、履行社会义务
  - 史瓦丹和海斯五假设：①个人主义比集体主义更敏感；②男性度高的个体不如女性度高的敏感；③高权力距离不如低权力距离敏感；④高不确定性避免比低更敏感；⑤长期化导向比短期化更敏感
- **伦理相对主义 vs 伦理绝对主义**：
  - 相对主义：道德观念具有极端相对性和条件性，否认普遍规律（普罗塔哥拉、霍布斯、洛克；新实证主义、实用主义、存在主义、境遇伦理学）
  - 绝对主义：善恶观念和道德规范永恒不变，主张适合一切时代民族的绝对道德真理（柏拉图"善"、基督教神意、康德"绝对命令"、杜林、斯宾塞、董仲舒"天不变道亦不变"）
  - 辩证结论：伦理的相对性与绝对性相互依存、相互兼容；伦理体系既是相对的又是绝对的；实践上应实现绝对性与相对性的统一
- **超文化规范**：较少依赖地域文化、适用于国际伦理环境的职业规范；符合内在一致性（与其文化中其他规范一致）和外在一致性（符合普遍性道德标准）两原则；代表伦理绝对主义的理想，构成人类伦理的根基（互助、互信、互惠等积极责任+禁止暴力、欺骗、背叛等消极责任）
  - 四大来源：①伦理学哲学宗教著作（黄金法则"己所不欲勿施于人"）；②法规文献（联合国《世界人权宣言》）；③国际知名工程组织章程（公众安全健康福祉首要）；④应用公认伦理理论（尊重人的伦理、功利主义）
  - **7种超文化规范**：尊重文化和法律；避免侵犯人权；促进东道国福祉；避免行贿送礼；保护健康和安全；保护环境；促进合理的背景制度
  - 两种决策风格：外国风格（入乡随俗）+帝国风格（伦理优越主义）→用"求同存异"解决冲突
- **最佳实践标准五大国际准则**：
  - 全球苏利文原则（1977）：维护全球人权、平等机会、尊重结社、提升员工能力、安全健康职场、公平交易、参与社区活动、融入营运、透明化
  - 考克斯圆桌企业原则（1991）：基于"共生"和"人格尊严"两个道德观念
  - 联合国全球契约（2000）：人权、劳工、环境、反腐败四大领域十大原则（安南1999达沃斯提出）
  - 国际SA8000标准：全球首个道德规范国际标准；保障劳工权益9方面最低要求（禁童工、禁强迫劳工、健康安全、结社自由、禁歧视、禁惩戒性措施、每周≤48小时、最低工资、管理体系）
  - ISO26000：社会责任指南标准；强调守法、关注利益相关方、透明度、可持续发展、人权与多样性
- **中国工程"走出去"价值原则**：在义利相兼（以义为先）、和而不同、务实有为、诚朴尽责四个传统价值观基础上拓展超文化规范；坚守"人类共同价值"而非普世价值观或文化相对论
- **"走出去"伦理规范六条**：①尊重理解当地政治及民俗文化（避免种族歧视和不当言论）；②遵守我国法律、东道国法律及国际规范惯例（重视合同条款设置）；③注重当地生态保护，可持续协调发展（做社会责任承担者，不做环境破坏者）；④超越把利润作为唯一目标的功利性理念；⑤遵守国际通行工程技术标准，对标准创新引领；⑥分享技术和工程产品，分享"中国制造"利益
- **"一带一路"生态伦理框架**：①坚持马克思主义生态伦理思想（自然、人、社会三视角；实践是人与自然伦理关系的前提；反对将人与自然对立）；②构建新的生态伦理价值取向（尊重自然前提下以人为本，绿色经济，重大决策优先考虑环境）；③大力发展生态环保产业（技术两面性，废弃物循环再利用）；④加强生态环境合作机制（"一带一路"绿色发展国际联盟、生态环境保护大数据服务平台）

## Key Concepts
- **文化（泰勒定义）**：一个复合体，包括知识、信仰、艺术、法律、道德、风俗及人作为社会成员获得的任何其他能力和习惯
- **文化（霍夫斯蒂德定义）**：同一环境中人民所具有的"共同的心理程序"
- **伦理相对主义**：断言道德观念具有极端相对性和条件性，否认道德发展的普遍规律
- **伦理绝对主义**：认为善恶观念和道德规范是永恒不变、超历史的范畴，主张绝对道德真理体系
- **超文化规范**：与本土或东道国道德标准相比较少依赖地域文化的职业规范，是最基本的伦理底线
- **黄金法则**：己所不欲勿施于人——人际关系的黄金法则，世界绝大多数伦理和宗教传统都包含
- **全球苏利文原则**：1977年建立，呼吁企业遵从法律及担负责任，促进人与人和谐谅解
- **SA8000**："社会责任标准"，全球首个道德规范国际标准，确保供应商产品符合社会责任标准要求
- **义利相兼，以义为先**：中国传统义利观，"一带一路"沿线各国相互尊重、平等相待、合作共赢的前提
- **和而不同**：多元共存、多样性意义上的平等共处，解决文明矛盾冲突的指导原则

## Mental Models
- **"入乡随俗 vs 全球一致"**：跨国工程管理标准的两难——博帕尔教训：联合碳化物公司采用"双重安全标准"（印度工厂低于美国标准）导致灾难
- **求同存异是国际伦理决策的核心原则**：把被所有文化共同包含的价值标准提炼出来
- **"本国标准"不能成为伦理优越主义**：不能因国家实力强大而认为本国伦理优于他国
- **文化差异根植头脑，很难轻易改变**：霍夫斯蒂德证实文化差异很难改变，须尊重理解
- **"一带一路"是生态保护的重地**：沿线生态脆弱、生物多样性富集——发展不能以牺牲环境为代价
- **人与自然辩证统一**：马克思主义生态伦理——自然是人的无机身体，人源于自然；以实践为中心理解人与自然关系
- **生态兴则文明兴，生态衰则文明衰**：杀鸡取卵、竭泽而渔的发展方式已走到尽头

## Anti-patterns
- **博帕尔式"双重安全标准"**：联合碳化物公司在印度采用低于美国的安全标准，无应急预警、无可靠存放场所、安全系统全部失灵、削减培训（6个月→15天）——"双重标准"是跨国工程的伦理红线
- **"以商业秘密为由"拒绝披露**：博帕尔事故后公司拒绝对公众和医疗单位提供异氰酸酯研究资料，延误救治——公众知情权高于商业机密
- **帝国风格（伦理优越主义）**：因本国强大而输出本国价值观和习俗，压制东道国文化
- **"项目二次经营"违规行为**：超低报价投标→中标后"挟工程以自重"要求变更条款多付款——违反国际规则和行业规范
- **卡拉库姆运河式短期逐利**：只顾农业经济效益截留阿姆河水，导致咸海从6.45万平方公里萎缩到不足10%——缺乏生态伦理思想的系统评估
- **文化冲突中的简单粗暴否定**：否定或取代他国文化必然引起激烈冲突与反抗

## Worked Example
**印度博帕尔毒气泄漏事故（引导案例）**：
1. 事件：1984年12月3日凌晨，美国联合碳化物公司印度博帕尔工厂异氰酸酯储罐泄漏，直接致死2.5万、间接致死55万、永久性残疾20多万。
2. 危险埋下：为节约成本自行生产剧毒异氰酸酯；1982年安全检查报告61处危险被忽视；安全培训从6个月缩至15天；6个安全系统全部失灵（冷却系统停一天省30美元）；员工裁员、1名操作员管70多只仪表。
3. 灾难处理失当：未向市民提供基本逃生建议；公司以"商业秘密"为由拒绝提供毒气研究资料；故意淡化事故影响；最终4.7亿美元赔偿（每人550-700美元）连5年医疗费都不够，还附"免除一切责任、取消刑事指控"条件；陶氏并购后拒绝承担善后。
4. 伦理教训：跨国企业"双重安全标准"；保护东道国公民健康安全是普遍接受的超文化规范；全球化悲剧——公司选择廉价劳动力、松懈规定、劣等工厂，惩罚最终落到博帕尔人身上。

## Key Takeaways
1. 文化差异五维度（个人/集体、权力距离、不确定性避免、男性/女性度、长期/短期取向）是理解跨国工程伦理冲突的基础工具。
2. 伦理相对主义与绝对主义各具真理性与片面性，须辩证结合：伦理的相对性与绝对性相互依存兼容。
3. 超文化规范（7种）是国际工程伦理的最低底线，代表伦理绝对主义理想，应"求同存异"提炼共同价值。
4. 最佳实践标准（苏利文原则、考克斯圆桌、联合国全球契约、SA8000、ISO26000）构成全球化企业社会责任参照系。
5. 中国工程"走出去"以义利相兼、和而不同、务实有为、诚朴尽责为价值原则，做负责任大国工程。
6. "一带一路"必须坚持马克思主义生态伦理，统筹人与自然和谐，走绿色发展道路。
