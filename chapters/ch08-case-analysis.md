# 第8章：工程伦理案例及分析

## Core Idea
本章是全书案例库，10个经典案例覆盖中国与世界工程史，每个案例均用"四论"（功利论、义务论、契约论、美德论）+关系人伦理困境+伦理守则规范三重框架分析，是全书的"实战演练章"。

## Frameworks Introduced
- **案例分析四论框架**（每案例通用）：
  - 功利论（成本-效益）：行为正当性取决于结果——工程决策看收益是否大于代价、是否最大化公共利益
  - 义务论（责任与义务）：行为正当性取决于是否履行义务——保护生命、提供安全产品是首要义务
  - 契约论（程序与契约）：行为正当性取决于是否符合约定程序——按契约与规范行动
  - 美德论（品质与诚信）：行为正当性取决于行为者品质——诚实、守信、负责是首要美德
- **关系人伦理困境分析法**：识别案例中各利益相关者（政府、管理层、工程师/操作人员、公众、受害者等），逐一分析其面临的伦理两难与应担责任

## Key Concepts（10案例要点）
- **京杭大运河**（P199-202）：全长1797km、贯通五大水系；开凿于春秋、竣工于隋、繁荣于唐宋、取直于元、疏浚于明清；隋炀帝急功近利致数百万劳工死亡——"功在当代利在千秋"与"数百万人命"的功利计算；监督官员面临"欺君之罪vs劳工生命"两难
- **奥的斯电梯**（P203-206）：2010深圳/2011北京地铁扶梯事故（T形螺栓设计缺陷+维护缺位）；公司拒绝承认缺陷、拒绝召回、拖延赔偿（对比法国辐射事件立即召回）；特种设备安全监管（《特种设备安全监察条例》）存在执行漏洞
- **N射线事件**（P207-210）：1903年法国物理学家布隆德洛声称发现N射线，120多位科学家发表300多篇论文，伍德教授通过暗室实验揭露真相（置换锉刀为木尺、拿走棱镜）；病态科学、民族主义介入科学；科学需要批判怀疑精神与诚实美德
- **奔腾芯片**（P211-214）：1994年英特尔浮点运算缺陷（90亿次除法错1次、27000年一遇），明知缺陷仍上市，被消费者发现后企图掩盖；被迫提供终身更换——企业知情不报违背诚信，最终召回补救挽回声誉
- **怒江水电站**（P215-218）：13个梯级电站规划（总投资896.5亿、年发电1029.6亿千瓦时），因环保争议经历七阶段十余年反复；经济利益vs生态保护vs民族文化保护vs移民安置的多方博弈
- **松花江水污染**（P218-221）：2005年吉林石化双苯厂爆炸，约100吨苯类物质入江，哈尔滨停水4天；操作人员两次违规操作是直接原因，应急预案缺失、信息通报迟缓、隐瞒真相延误处置；环保总局局长辞职
- **三聚氰胺毒奶粉**（P222-225）：2008年三鹿事件，约700吨受污染奶粉流入市场；原奶涨价压力转嫁奶农→掺水→加"蛋白精"三聚氰胺形成行业潜规则；监管分段体制存在漏洞盲区
- **三星半导体**（P225-228）：200多名员工患病、76人死亡（白血病等16种疾病），公司11年拒不承认，最终2018年达成调解（白血病赔偿1.5亿韩元/人+500亿韩元基金）；政府纵容"丢卒保车"、雇佣廉价劳动力缺乏培训
- **福岛核事故**（P228-232）：2011年3.11地震+14米海啸（防御设计仅5.7米）摧毁应急电源；马克1型反应堆设计瑕疵（通用电气为成本利润未采纳工程师关停建议）；东京电力篡改安全数据28次、事故后污水直接排海；定为7级特大事故
- **港珠澳大桥**（P232-237）：55km桥隧工程（桥、岛、隧三位一体），"一国两制"三地协同工程典范；香港段混凝土压力测试造假丑闻、多起工人死亡事故；设计上S形曲线减少阻水率、保护中华白海豚、低于10%阻水率要求；绿色发展生态优先成为未来工程范式

## Mental Models
- **"四论交叉验证"**：单一伦理理论各有盲区，用功利（结果）、义务（责任）、契约（程序）、美德（品质）四个视角交叉检验工程决策
- **"100-1=0"式信任危机**：一次缺陷隐瞒（奔腾、奥的斯）足以摧毁企业多年积累的信任
- **"监管滞后于技术"**：特种设备条例、分段食品监管、核电安全审查均暴露"设计-监管-执行"的缝隙
- **"概率再小也是责任"**：奔腾芯片90亿分之一、T形螺栓设计缺陷——低概率风险一旦发生就是100%的生命代价
- **"工程师的发言义务"**：通用电气工程师建议关停未通过测试的核电站、伍德揭露N射线——发现隐患必须发声
- **"利益相关者平衡"**：怒江案例证明超级工程是多方利益的博弈场，须协调政府、企业、居民、环保诉求
- **"生态优先是工程新范式"**：港珠澳大桥证明超级工程可以与环境保护兼得（S形曲线、白海豚保护、阻水率<10%）

## Anti-patterns
- **隐瞒缺陷**：奥的斯（设计缺陷不承认）、英特尔（已知缺陷不召回）、东电（28次篡改数据）、三星（11年不认账）——隐瞒只会放大损失
- **为赶工期牺牲安全**：京杭大运河（1个月完工令）、港珠澳大桥香港段（混凝土测试造假疑与赶工有关）、松花江（违规操作）
- **"双重安全标准"**：联合碳化物公司在印度降低标准（第7章）与奥的斯在华标准低于国外——跨国企业伦理红线
- **利润优先于生命**：通用电气明知马克1型瑕疵不改进、三鹿为降本添加三聚氰胺、三星雇佣廉价劳力不培训
- **监管不作为/纵容**：韩国政府纵容三星、日本监管机构保护东电利益、分段监管盲区（三聚氰胺）、质检部门监管漏洞
- **民族主义扭曲科学**：N射线事件中法国科学家用沙文主义反驳科学证据
- **信息不透明**：松花江事件中隐瞒真相10天、博帕尔以"商业秘密"拒绝提供资料

## Worked Example
**福岛核事故完整链条（引导案例）**：
1. 设计隐患：通用电气马克1型围阻体（建造容易、尺寸小、成本低），内部文件曝光称"未经足够测试、存有影响安全的设计瑕疵"，工程师建议关停未完成安全测试的核电站未获采纳。
2. 历史隐瞒：1978年临界事故隐瞒至2007年；199次定期检查中篡改数据；1号机组主蒸汽管流量数据1979-1998年间28次被改。
3. 灾难触发：2011.3.11 9.0级地震→全厂外电丧失→46分钟后14米海啸（设计防御5.7米）冲毁防御设施→仅存1台应急发电机→全部交直流电源丧失→堆芯余热升温→锆包壳与水反应产氢→爆炸→3台机组压力容器失效。
4. 处置失当：事故后优先考虑恢复发电而非安全；污水冷却水直接排海；故意淡化隐瞒事故严重程度；赔偿拖延。
5. 伦理启示：不存在绝对安全的设计；设计瑕疵+隐瞒数据+监管失职+应急失灵的多重叠加；政府与企业的社会责任在灾难面前无所遁形。

## Key Takeaways
1. 10个案例覆盖产品安全（奥的斯、奔腾）、工程开发（怒江、港珠澳、大运河）、环境污染（松花江、福岛）、食品安全（三聚氰胺）、劳工权益（三星）、科学诚信（N射线）六大主题，是期末分析题的最佳素材库。
2. 分析题的通用答题框架：四论（功利/义务/契约/美德）逐层分析→关系人伦理困境逐一剖析→伦理守则对照→提出改进建议。
3. 所有事故的共同根源：缺陷隐瞒+利润优先+监管失灵+信息不透明；工程师的第一伦理责任是"发现隐患必须发声"。
4. 工程伦理守则（台湾守则条款：涉及公共事务考虑社会利益、熟知法规纠正不当情事、尊重自然爱护生态等）是案例分析的规范对照工具。
